# AI Placement Preparation Assistant

An AI-powered interview preparation application
built using LangChain, OpenRouter and Streamlit.

## Features

- Role-based interview preparation
- Experience-level selection
- Custom difficulty selection
- AI-generated interview questions
- Model answers and explanations
- Structured output using Pydantic

## Tech Stack

- Python
- LangChain
- OpenRouter
- Pydantic
- Streamlit

## Installation

1. Clone the repository.

2. Create virtual environment:

   python -m venv venv

3. Activate environment:

   venv\Scripts\activate

4. Install dependencies:

   pip install -r requirements.txt

5. Configure your .env file.

6. Run:

   streamlit run app.py
